# JoyOrbit GNU engine integration

Corresponding source for the separate GNU Backgammon process used by JoyOrbit. Original GNU and facade notices remain in COPYING, NOTICE and PROVENANCE.md. The copied recipes match joyorbit-app/scripts; use the full JoyOrbit checkout for Android AAR packaging and the Godot interface. They pin this facade at eb538998513c4171f4f6392c7c15a0bdb7ef83e5, GLib2.88.1, libiconv1.18 and the upstream Meson fallback checksums. JoyOrbit supplies its own name, interface and artwork; no CBG front end, marks or optional paid features are included in its binary.
